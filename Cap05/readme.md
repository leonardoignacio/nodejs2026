# Cap05 - Banco de Dados e CRUD

Este capítulo introduz acesso a banco de dados, criação de esquemas SQL e operações CRUD.

## Conteúdo
- `at01-CreateDatabase/`
- `at02-AcessoAoBanco/`
- `at03-CrudCompleto/`
- `at04_CrudAtuhMvc/`
- `at05_CrudORMPrisma/`

## Objetivos
- Criar banco de dados e tabelas
- Conectar-se ao banco com Node.js
- Implementar CRUD completo
- Explorar ORM com Prisma

## Como executar
```bash
cd Cap05/at02-AcessoAoBanco
npm install
node index.js
```

## Observações
Algumas atividades usam MySQL e PostgreSQL. Confira o `envExemple` e ajuste as variáveis de ambiente conforme seu banco.
